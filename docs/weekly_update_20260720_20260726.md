# 上周项目更新汇总（2026-07-20 至 2026-07-26）

本周改动集中在四条主线：缠论沙盘 V2、每日复盘流程、高手发言抓取、高手发言阅读与发布看板。

## 1. 缠论沙盘 V2

### 界面与操作

- 将沙盘 V2 整理为独立前后端应用，并保留本地一键启动、停止入口。
- 默认使用 `5m` 观察周期，默认显示 `5m + 30m` 级别；默认勾选 `30m` 笔、笔中枢、笔买卖点和 MACD。
- 右侧“结构 / BS点 / 小转大”标签改为单行布局；已激活的 BS 点标签可以再次点击取消。
- `5m` 与 `30m` 使用橙色、蓝色两套明显不同的色系，笔与线段也使用不同线型和颜色，降低图层混淆。
- 时间滑块覆盖全部有效数据，滑块两端对应当前显示区间的开始、结束日期；结束日期自动对齐最新交易日。
- 最新 K 线右侧保留后续交易空间，缩放时使用非过滤模式，避免端点在视区外时整条笔或线段消失。
- 增加“一键全部更新”，可依次同步自选标的，并显示成功、失败进度。

### MACD 与背驰分析

- MACD 默认开启，并恢复高一级别 MACD 面积的浅色半透明背景。
- 修正 MACD 零轴定位和背景色透明度。
- 背驰比较按结构方向累计同侧柱面积：向上结构比较零轴上方柱面积，向下结构比较零轴下方柱面积。
- 同时比较 MACD 面积、峰值和 DIF，使用三项证据中至少两项减弱的判定规则，并保留价格创新值前提。
- 背驰区间表的备注统一为“背驰 / 无背驰”，确认项使用绿色强调。

### 实验性结构对比

- 增加“实验：结构对比”开关，关闭后不影响正式 BS 点逻辑。
- 点击某一笔或线段时，自动寻找最近一段同级别、同类型、同方向结构。
- 展示价格幅度、MACD 面积、MACD 峰值、DIF、平均成交量等对比，并给出实验性背驰结论。
- 实验逻辑集中在独立模块中，便于后续调整或整体回滚。

### 数据同步与质量

- 新浪 K 线同步改为增量请求：依据本地最新时间动态计算需要获取的条数，减少流量和等待时间。
- 合并时只追加本地水位线之后的新记录，不用远端重叠区间覆盖本地已校正历史。
- 为增量请求和只追加合并增加自动化测试。
- `sh588200` 的 1:3 份额拆分数据已在本地行情源完成复权校正；校正数据和备份属于本机数据资产，不进入 Git。

## 2. 每日复盘

- 整理每日复盘入口、生成脚本和流程说明，保留本机目录兼容逻辑。
- 复盘计划、判断结果和临时 HTML 均视为运行产物，不再提交到仓库，避免历史输出覆盖源码改动。
- 将“源代码 / 配置模板”与“每日生成结果 / 本地数据”分开管理，仓库只维护可复现流程所需内容。

## 3. 高手发言抓取

- 抓取过程改为复用浏览器会话，避免每完成一个跟踪对象就重新创建空白浏览器窗口。
- 收集脚本只负责抓取，不再自动启动阅读看板。
- NGA 增加繁忙页、网络变化和响应体失效等情况的重试与恢复处理，重试上限可配置。
- 虎扑、雪球继续复用本地登录资料，并保留单站点重新登录入口。
- 本地 SQLite 数据库继续作为唯一事实源；Markdown / JSONL 仅作为可选导出，不再作为看板中间层。
- 新增结构化回复解析，明确分离“跟踪对象本人的发言”和“被引用发言”，保存 `rawText`、`quote`、`replyChain` 及解析状态。
- 增加回复结构测试，覆盖 NGA、雪球、虎扑以及历史记录兼容情况。

## 4. 阅读看板与 GitHub Pages

- 本地阅读看板直接读取 SQLite 数据库，支持今天、最近 3 天、最近 7 天和全部日期。
- 支持网站、分类、关键词、作者导航等筛选，并单独展示引用链，不把引用内容混入作者正文。
- 看板服务与抓取脚本分离，可独立启动和刷新数据库内容。
- GitHub Pages 发布也拆成独立入口，直接由本地数据库生成发布数据，抓取失败时无需重跑全量收集才能再次发布。
- 发布流程增加远端分支同步处理，降低本地发布仓库与远端历史分叉导致的失败概率。

## 5. 常用入口

- 缠论沙盘：`01_chanlun_sandbox/v2/启动沙盘V2.bat`
- 收集今日发言：`02_daily_replay/一键收集今天发言.bat`
- 打开本地看板：`02_daily_replay/打开高手发言阅读看板.bat`
- 发布到 GitHub Pages：`02_daily_replay/发布高手发言到GitHub Pages.bat`

## 6. 仓库边界

以下内容保留在本机，但不进入 Git：

- SQLite 数据库、浏览器登录资料和运行日志。
- 每日生成的复盘计划、判断 JSON、临时看板 HTML。
- `sh588200` 校正后的本地行情文件及其备份。
- 临时备份文件和编译产物。

这样可以保证更新代码时不会覆盖本地数据，也不会把个人登录状态或大量运行产物推送到远端。
