## 当前产品范围

- 页面只保留实时分析，不再显示 Replay、研究、标注、威科夫和波浪入口。
- 默认进入 `30m 决策`；`5m 观察`用于执行层细化，日线可作为更高级别背景。
- 切换标的后自动重新分析；日期起点只裁剪显示，结构和指标始终使用结束日期以前的全部可用历史自左向右计算。
- 图层按 5m、30m、日线分组，可独立显示笔、线段、笔中枢、段中枢、BS 点和 MACD。
- 点击 BS 点后，右栏展示原生类型、发生与确认时间、父点依赖，以及对照段和检验段的价格、MACD、DIF、成交量证据。
- 结构页把当前判断、关键边界和条件式应对合并展示，不再使用抽象的结构等级或仓位等级。
- 快照与导出仍是实时页的正式功能。Replay、标注接口暂作为兼容 API 保留，但不进入当前页面流程。

## 结构口径

- 顺序为 `包含处理 → 分型 → 笔 → 笔中枢与笔 BS 点 → 线段 → 线段中枢与线段 BS 点`。
- 5m 笔、5m 线段、真实 30m 笔分别保留原始身份；5m 线段 BS 点标记为 `5m段`，不会冒充 30m 笔 BS 点。
- 5m、30m、日线分别使用对应周期行情独立计算，同一组折点不会同时充当笔和线段。
- 一类点与类一类点采用严格动力复核：价格必须创新值，且 MACD 面积、MACD 峰值、DIF 极值三项中至少两项不高于对照段的 `0.85×`；成交量只作辅助证据。
- 事件位置与确认时间分开记录；未确认末端结构和动力证据不足的一类点只保留为候选。
- 每个 `chan.py` 原生 BS 位置只生成一个沙盘点；复合类型保留为一个标签，例如 `笔S2s,3b`。
- 二类点必须继承同级别关联一类点的复核状态；父点为候选时二类点只能是候选，父点失效时同步失效。
- 没有满足当前级别完整结构时允许图层为空，不用低级别信号填充高级别图表。
