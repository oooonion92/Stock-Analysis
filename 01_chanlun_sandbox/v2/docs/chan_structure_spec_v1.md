# 缠论结构与信号规格 v1

## 1. 目标与边界

本规格定义可被程序验证的结构语义。判断顺序固定为：可见行情前缀、包含处理、确认分型、笔、线段、同级别中枢、离开与回抽、买卖点生命周期。MACD 与成交量只能提供辅助证据，不能移动已确认的缠论端点。

任何尚有口径争议的条目必须进入人工黄金样本裁定，不得用参数调整临时掩盖。

## 2. 时间与不可变性

- `event_at`：结构在图上的发生位置。
- `detected_at`：算法首次识别出候选的时间。
- `confirmed_at`：仅使用当时可见数据即可确认的时间。
- `invalidated_at`：后续结构条件被破坏的时间。
- `as_of` 与 `visible_bar_end`：本次计算实际可见的最后时点。

同一 `as_of` 的输出必须等于仅输入该时点之前行情所得输出。已确认结构不可因未来行情移动；允许新增后续结构、延伸中枢结束时间，或使候选失效。

## 3. 基础结构

### 3.1 包含处理

包含关系按当时已确定的方向逐根合并，合并后的高低点必须保留来源 K 线与首次可见时间。方向尚未确定时，不提前借用未来方向。

### 3.2 分型

顶/底分型以处理后的连续三元素定义。中间元素是 `event_at`，第三元素完成后才有最早 `confirmed_at`。候选分型可被后续包含或同向极值替换；一旦确认，只能由更高层结构引用，不能回移。

### 3.3 笔

笔连接相邻、异型、已确认分型。起止分型之间必须满足独立元素数量与价格区间约束。相邻同型分型只保留更极端者，且替换行为只能发生在该端点确认之前。

待人工裁定：严格笔与新笔的最小间隔采用哪一口径，以及一字/缺口行情的边界处理。

### 3.4 线段

线段的输入只能是同级别已确认笔，不能直接对 K 线再次取峰谷。线段端点必须记录构成笔、破坏方式和确认笔；没有确认破坏时只能是候选线段。

待人工裁定：特征序列包含处理及第一/第二种破坏的边界样本。

## 4. 中枢与级别

### 4.1 同级别中枢

中枢由同一级别至少三个连续次级别走势段的重叠区间形成：`ZD=max(各段低边界)`，`ZG=min(各段高边界)`，且 `ZD <= ZG`。中枢必须记录其构成段，不允许仅按空间框重叠合并。

### 4.2 延伸

后续同级别走势段继续与原 `ZD/ZG` 重叠，属于同一中枢延伸。延伸只能更新结束时间和构成段数量，不重写起点及初始确认时间。

### 4.3 扩张与升级

两个同级别中枢之间发生第三类买卖点失败或区间重新重叠，并形成更高一级别的连续结构时，产生扩张候选。升级必须由更高一级别的线段输入重新构造；不能把多个小框按时间或空间并集直接画成一个超长大框。

升级后的高一级中枢拥有独立 ID、构成结构和确认时间。默认视图可隐藏其覆盖范围内的重复小级别框，但数据库必须保留原结构。

### 4.4 活跃结构归属

每个时点、每个级别最多有一个活跃中枢。每个买卖点必须绑定唯一的 `center_id`、`level` 与离开段/回抽段，禁止同一转折同时复制为多个级别信号。

## 5. 买卖点状态机

所有信号经历 `candidate -> confirmed -> risk_downgraded -> invalidated/expired`。图上标记发生位置，但必须同时展示确认时间。

`confirmed` 只描述信号在当时可见行情下成立，不代表永久有效。确认后，买点收盘价有效跌破风险线、卖点收盘价有效升破风险线时转为 `invalidated`；必须保留原 `confirmed_at` 并另记 `invalidated_at`。默认图层隐藏失效点，历史图层仍可追溯。

### 5.1 一类买卖点

一买/一卖建立在同级别趋势结构完成与背驰证据之上，不建立在任意单笔极值或单次 MACD 金叉死叉上。趋势未完成时只能标记“潜在背驰观察”，不得标记 `1B?` 或 `1S?`。

### 5.2 二类买卖点

一类买卖点后的首个同级别反向回撤不创新低/新高，并在后续同级别结构确认后成立。它必须引用对应的一类买卖点或等价趋势转折结构，并继承父一类点极值作为整条信号链的风险线。

### 5.3 三类买卖点

三买必须依次满足：向上离开中枢、首次同级别回抽不进入 `ZG`、后续向上结构突破确认。三卖镜像。回抽低点/高点是 `event_at`，突破发生时才是 `confirmed_at`。

只有弱回调或动能改善而没有中枢离开与首次回抽关系时，只能记录“类三买/类三卖”，不得混入正式 3B/3S 统计。

### 5.4 小转大事件

小转大是跨级别结构事件，不属于原生30m买卖点。首期来源限定为已经通过严格复核的5m一类或类一类点；其后必须先以5m收盘突破当时已经确认的最近线段端点，再以30m收盘越过同一边界确认。来源极值是风险线，确认后有效破坏风险线仍转为失效。

图上标记实际的来源可见、突破触发或30m确认时间，不将后续确认回填成来源时刻已经可操作的信号。成交量与MACD只作为触发证据展示，不设置综合等级。

### 5.5 级别升级与去重

信号级别由其所属中枢和完成该结构的线段级别决定，不由图表周期或视觉振幅决定。更高一级信号确认后，默认视图抑制同一结构上的低级别重复标签；低级别信号仍保留在历史证据链。

## 6. 黄金样本字段

人工标注必须至少包含：

- `gold_schema_version`、`symbol`、`data_hash`、`visible_bar_end`；
- `kind`、`level`、`human_status`；
- `event_at` 与 `event_price`；
- 已确认结构的 `confirmed_at`；
- 笔/线段的起止点及方向；
- 中枢的起止点、`ZD`、`ZG`；
- 买卖点的类型、所属中枢和文字依据。

人工状态为 `confirmed`、`candidate` 或 `rejected`。争议样本不得强行进入 confirmed。

## 7. 新核心验收门槛

1. 每个黄金样本逐项对比端点、级别、确认时间和结构归属。
2. 对任意时间前缀重复计算，确认结构及其 ID 保持一致。
3. 正式 BS 点不得依赖未来收益、后续最高最低价或人工画框之外的信息。
4. 误报、漏报分别统计，不能只用信号数量或视觉相似度验收。
5. 自动结果与人工裁定冲突时输出差异，不静默覆盖人工样本。
