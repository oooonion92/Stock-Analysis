## 冻结范围

本标签完整冻结以下可复现行为：

1. CSV 校验、周期聚合和全历史预热后按日期裁剪显示。
2. 5m、30m、日线独立计算的分型、笔、线段及两类中枢。
3. `chan.py` 原生笔/段 BS 点映射、复合标签和父一类点依赖。
4. 一类点价格创新与 MACD/DIF 两票动力复核。
5. 候选、确认、风险降级、失效和过期生命周期。
6. 30m 默认视图、分组图层、缩放标签裁剪和 BS 点证据对比。
7. 结构事实、关键边界与条件式应对合并后的右栏。

威科夫、波浪及旧标注面板不属于本基线；对应孤立实现已删除。分析响应暂保留空兼容字段，避免旧调用方立刻失败。

## 后续修改规则

- 修复不改变口径的缺陷时递增补丁号，例如 `1.0.1`。
- 改变 BS 判定、中枢构造、级别映射或确认时点时递增次版本，并补充黄金样本与前缀一致性测试。
- 不修改、重打或删除 `chanlun-sandbox-logic-v1.0.0` 标签。
- 新逻辑验收前保留 V1 标签作为并排输出和截图复核基准。
- 回滚核对优先新建独立 worktree，避免覆盖当前工作目录。

示例：

```powershell
git worktree add '..\Stock Analysis-chan-v1' chanlun-sandbox-logic-v1.0.0
```

## 最低验收

每次涉及核心结构的修改至少通过：

1. 后端单元测试和 API Schema 校验。
2. 任意日期起点只影响显示、不影响同一结束时点的结构结果。
3. 前缀一致性：当时确认的结构不被未来数据改写。
4. 上证指数与沪电股份的 5m/30m 关键样本对比。
5. 前端生产构建及 30m、5m 页面切换检查。
