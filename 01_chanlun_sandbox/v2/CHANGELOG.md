# 变更记录

## 1.1.0-cross-level-exp1 - 2026-07-19

- 在 `v1.0.1` 冻结标签上增加独立的 `5m→30m` 小转大事件链，不改名或覆盖原生30m BS点。
- 来源限定为当时已经严格确认的5m一类/类一类点，突破边界限定为当时已确认的最近5m线段端点。
- 生命周期拆分为候选、5m突破触发、30m收盘确认和风险线失效，所有阶段保留各自时间。
- 触发证据增加20周期量比、DIF、DEA与MACD柱，仅用于解释，不设置综合等级或硬门槛。
- 增加独立图层与中文证据页；图标落在实际可见、触发或确认时间，不回填伪装成提前信号。

## 1.0.1 - 2026-07-19

- 补齐确认信号的后续失效回收：收盘价有效破坏风险线后退出当前严格信号，保留确认与失效两个时间。
- 二类点继承关联一类点的风险线和最终生命周期状态，避免父链破坏后仍显示为严格确认。
- 修正“失效历史”图层开关，默认隐藏失效点，开启后仍可追溯历史证据。
- 新增上证指数 2026-05-28 与 2026-06-02 两组买点链及前缀无前视测试。

## 1.0.0 - 2026-07-19

- 将固定版 `chan.py` 结构适配正式固化为 Chan 逻辑 V1。
- 冻结 5m/30m/日线独立结构、笔/段中枢、BS 点依赖与动力复核口径。
- 默认使用 30m 决策视图，保留 5m 执行观察与日线背景。
- 结构事实、关键边界和条件式应对合并到同一右栏。
- 页面收敛为实时分析；移除不再参与运行的威科夫、波浪和旧标注面板实现。
- 保留快照、导出及必要兼容 API。
